Cada cenário foi montado **exclusivamente** com assets do seu próprio pack.
Estes arquivos estão aqui **apenas para avaliação** — confirmar a licença antes
do uso final no jogo.

| Código | Pack | Origem / Licença |
|---|---|---|
| `S-floresta-sunny`   | SunnyLand          | ansimuz — **CC0** (via repo phaserjs/editor-example-sunny-land-forest) |
| `S-floresta-pack01`  | Pack 01 Pixel Art  | Forest Pack (grátis) — enviado pelo usuário |
| `S-floresta-fantasy` | Legacy Fantasy High Forest | grátis — enviado pelo usuário |
| `S-medieval`         | GandalfHardcore Platformer | grátis — enviado pelo usuário |
| `S-pos-apocalipse`   | Post Apocalypse Backgrounds | grátis — enviado pelo usuário |
| `S-zona-guerra`      | War Pixel Art Backgrounds | grátis — enviado pelo usuário |

(céu + camadas + props), feitas só para pré-visualizar o cenário montado.
